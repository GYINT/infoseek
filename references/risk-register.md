## 2. 监控计划

| 维度 | 方式 | 触发动作 |
|------|------|----------|
| 测试回归 | `python tests/run_tests.py` | 任何 FAIL → 阻止发布 |
| 性能漂移 | `dist/quality_baseline.json` 对比 | 关键指标劣化 >10% → PATCH |
| 搜索可用性 | 引擎超时/429 日志 | 连续失败 → 检查降级链配置 |
| OSINT 契约 | 双源 CLI 采样（Maigret/Sherlock） | 解析字段缺失 → 隔离 venv 复核 + 契约测试 |
| 人因红线 | `PRIVACY.md §4/§6` + `network-boundary-report §4` 复核 | 触及设备/客户端指纹 → 立即否决并冻结 |
| 默认开关 | 注册表 `enabled` 与 env 旁路对拍 | 默认 OFF 被 env 绕过 → 补测试隔离 |

## 3. 环境感知跳过

- POSIX-only（`import resource`）→ Windows 自动跳过内存维度
- 可选依赖缺失（jieba/summa/playwright）→ 自动降级零依赖 NLP / L1 抓取
- 网络超时 → 引擎级降级，不误报 FAIL

## 4. 已知限制（如实声明）

- `fetch_content` L2-L4 已接线（L2 渲染 / L3 凭证 / L4 多媒体；L1 静态抓取 v1.0.1 落地）；远端 host 在沙箱受限时自动降级 L1
- 搜索质量依赖网络环境：DDG/Jina 受限时仅 Bing 存活，中文召回偏低（建议配 Exa/Tavily key）
- references 契约文档 v1.0.1 补齐（此前 8 份缺失）
- OSINT 双源（Maigret 0.6.5 / Sherlock 0.16.2）需隔离 venv；沙箱不支持真机 → 误报阈值标定待 P1（Phase-A/B/C）
- B 层 LLM 收口默认关闭（须 `INFOSEEK_ENABLE_*` 显式开启）；字段以白名单守护，不静默伪造
- 人因指纹增强（HF-R1）：P0 已落「字段 + 规则骨架」（默认关闭，待真实样本校准）；P1 需真实样本；P2 设备层窄口暂缓
- 融合协同簇因子（HF-P1）：D 因子 + 四因子重归一化 + 样本契约/校准套件已就绪，**权重最终值与生产 FPR 待真实样本**（接入契约见 `references/hf-real-sample-schema.md`）
